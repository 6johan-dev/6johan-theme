# Admin タスクリスト（パイロット商品向け）

このドキュメントは、テーマ側の改修と並行して Shopify Admin で実施が必要な作業の一覧です。

## 1. メタフィールド定義（一度だけ）

Shopify Admin > 設定 > カスタムデータ > 商品 から以下を **新規追加**:

| 名前 | 名前空間とキー | コンテンツタイプ |
|---|---|---|
| 重量 | `custom.weight` | テキスト > 単一行テキスト |
| 耐荷重 | `custom.weight_capacity` | テキスト > 単一行テキスト |
| 原産国 | `custom.origin` | テキスト > 単一行テキスト |

→ 一度定義すれば、全商品でこのフィールドが使えるようになります。

## 2. シルバーフレームラタンチェアの編集

Shopify Admin > 商品 > シルバーフレームラタンチェア で以下を更新:

### 2-1. SEO（Search engine listing）
`silver-frame-rattan-chair-final.md` の「1. Search engine listing」を参照してコピペ。

### 2-2. 商品説明（Description）
同ファイルの「2. Description」を参照してHTMLビューに貼り付け。

### 2-3. メタフィールド値の入力
同ファイルの「3. メタフィールド登録」の値リストを参照。
- 重量・耐荷重・原産国は実物を確認して入力
- 既存項目（measurements / material / is_assembly 等）は既に値があるか確認

### 2-4. 在庫設定
PDPバッジが正しく出るために：
- 在庫がある場合: バリアントごとに在庫数を正しく入れる、または「即納商品」コレクションに含める
- 受注生産: 在庫数 0 + 「在庫なしでも販売を続ける」をオフ にすると `受注生産` バッジが出る
- 残りわずか: 在庫数 1〜3 で `残りわずか` バッジに自動切替

## 3. 反映確認

テーマpush後、ストアフロントで確認:

- [ ] `https://6johan.com/products/silver-frame-rattan-chair` を開く
- [ ] 価格直下に在庫バッジが表示されている
- [ ] 「カートに追加」ボタンの下にスペック表が表示されている
  - サイズ / 素材 / 重量 / 耐荷重 / 原産国 / 梱包サイズ / 組み立て の項目
- [ ] 商品説明にH2見出し（5本）が表示されている
- [ ] ブラウザの「ページのソースを表示」で `<title>` と `<meta name="description">` を確認
- [ ] スマートフォンでも同様に表示されている

## 4. パイロット完了後の展開

このパイロットで決めたテンプレートを、他商品に展開する手順:

1. メタフィールド定義は完了済みなので、商品ごとに値を入れるだけ
2. 商品説明HTMLは「リード文 + H2 5本」構造をテンプレートとして使い回す
3. メタタイトル/ディスクリプションは下記フォーマットを使う:

**Page title フォーマット** (32字以内)
```
[主軸KW] [副軸KW]｜[用途]｜6JOHAN
例: ラタンチェア カンチレバー｜ダイニング・在宅ワーク｜6JOHAN
```

**Meta description フォーマット** (115-130字)
```
[素材＋特徴]。[使い方/座り心地など]。[用途1]から[用途2]まで。30日返品・1年保証・送料無料、在庫あり7日以内発送。
```

## 5. NGワードリスト（誇張表現）

以下の表現は使用禁止（ブランドガイド「誠実・控えめ」と矛盾）:

- 圧倒的、究極、最高、No.1
- アートピース、革命的、伝説の
- 死角のないデザイン
- 他では味わえない、決して味わえない
- 絶妙な、圧巻の
- 劇的に〇〇

代替: 「自然になじむ」「長く使える」「ちょうどよい」「丁寧な」「穏やかな」「すっきりとした」など。
